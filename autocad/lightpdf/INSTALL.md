# LightPDF 導入手順書

## 1. ファイルを置く

`LightPDF.lsp` を任意のフォルダに置きます（例: `C:\CAD\lisp\LightPDF.lsp`）。

## 2. 推奨：軽量 PC3 を作る（初回のみ・約3分）

-PLOT コマンドからは「レイヤ情報」「文字のジオメトリ変換」「解像度」を指定できません。PC3 側で一度だけ設定してください。

1. AutoCAD で `PLOTTERMANAGER` を実行します。
2. `AutoCAD PDF (Smallest File).pc3` をコピーし、`LightPDF.pc3` に名前を変えます。
3. `LightPDF.pc3` をダブルクリック →［デバイスとドキュメントの設定］→［カスタム プロパティ］の順に開き、次のように設定します。

| 項目 | 設定 | 理由 |
|---|---|---|
| ベクター品質 | **400 dpi** | 座標点を減らす |
| ラスター イメージ品質 | 200 dpi 程度 | 画像を軽くする |
| レイヤ情報を含める | **オフ** | Acrobat がレイヤを解析しなくて済む（必須） |
| 図面で使用されているフォントをキャプチャ | オン | TTF を本物のテキストとして埋め込む |
| すべての文字をジオメトリに変換 | **オフ** | 文字の線画化を防ぐ（必須） |
| ハイパーリンクを含める／しおりを作成 | オフ | 余計なデータを省く |

4. `LightPDF.lsp` の先頭を次のように書き換えます。

```lisp
(setq *LP:PC3* "LightPDF.pc3")
```

> PC3 を作らずに標準の `AutoCAD PDF (Smallest File).pc3` のまま使うこともできます。その場合は、同じ画面で上の「必須」2項目がオフになっているか確認してください。

## 3. 設定を環境に合わせる（LightPDF.lsp の先頭）

| 変数 | 内容 | 例 |
|---|---|---|
| `*LP:Paper*` | 用紙名（PC3 にある名前と完全に一致させる） | `"ISO full bleed A3 (420.00 x 297.00 MM)"` |
| `*LP:Orient*` | 向き | `"_L"`（横）／`"_P"`（縦） |
| `*LP:CTB*` | 印刷スタイル | `"monochrome.ctb"`、現在の設定のままなら `""` |
| `*LP:HeavyLayers*` | 印刷しない画層（大文字で書く） | `"*HATCH*,*ハッチ*"` |
| `*LP:TTF*` | 差し替える TrueType フォント | `"msgothic.ttc"` |

用紙名がわからないときは、コマンドラインで `-PLOT` → `Y` → Enter → PC3 名 → `?` と入力すると一覧が出ます。

## 4. 読み込み

- **その場で使う**：`APPLOAD` → `LightPDF.lsp` を選んで［ロード］
- **毎回自動で読み込む**：`APPLOAD` →［スタートアップ登録］の［内容］→［追加］→ `LightPDF.lsp`
- 初回は「信頼できる場所」の警告が出ることがあります。`OPTIONS` →［ファイル］→［信頼できる場所］にフォルダを追加すると、警告が出なくなります。

## 5. 実行

1. 図面を一度保存します（出力先が図面と同じフォルダになるため）。
2. 出力したいタブ（モデルまたはレイアウト）を開きます。
3. コマンド `LIGHTPDF` を実行します。
4. `<図面名>_light.pdf` が作られます。同名のファイルがある場合は `_light_1.pdf` のように連番が付き、既存ファイルは上書きされません。

モデル空間では「図形範囲を用紙にフィット」、レイアウトでは「レイアウトを 1:1」で出力します。

## 6. 確認

- 実行後、画面上の画層・文字は元のままです（UNDO も1回で戻せます）。
- Acrobat で「PDFを編集」を開き、待ち時間が短くなったか確認してください。
- まだ重い場合は、`*LP:HeavyLayers*` に重い画層（地図、写真トレース、点群など）を追加してください。

## トラブルシュート

| 症状 | 対処 |
|---|---|
| 「PDF が作成されませんでした」 | `*LP:PC3*` と `*LP:Paper*` の名前を確認する（全角・半角、空白も一致させる） |
| 文字がまだ線になる | PC3 の「すべての文字をジオメトリに変換」をオフにする。MTEXT 内で直接指定したフォントは差し替えの対象外 |
| Acrobat にレイヤパネルが出る | PC3 の「レイヤ情報を含める」をオフにする |
| 文字の幅が図面と少し違う | SHX と TTF の字幅の差によるもので、PDF にだけ現れる。図面データは変わらない |
