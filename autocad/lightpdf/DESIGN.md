# LightPDF ロジック設計メモ

TASK-20261002-autolisp-lightpdf / step 1 の成果物

## 問題

AutoCAD が出力した PDF を Acrobat の「PDFを編集」で開くと、約30秒フリーズする。
Acrobat は編集モードに入るときにページ内のパスとテキストをすべて解析する。解析にかかる時間は**パスの数と精度**で決まる。

## Acrobat の負荷になる要素と対策

| # | 負荷になる要素 | 対策 | 実装箇所 |
|---|---|---|---|
| 1 | ベクター精度が高すぎる（座標点が多い） | Smallest File 系 PC3（ベクター 400dpi） | `*LP:PC3*`／PC3 の設定 |
| 2 | ハッチング（1つで数百〜数千本の線分） | 該当する画層を一時的に「印刷しない」にする | `LP:hide-heavy` |
| 3 | SHX 文字（1文字が多数の線分になる） | 文字スタイルを一時的に TrueType へ差し替え、PDF 上で本物のテキストにする | `LP:ttf-styles` |
| 4 | SHX の注釈（PDFSHX=1 で1文字ごとに注釈が増える） | `PDFSHX=0` | `LP:sv-set "PDFSHX"` |
| 5 | レイヤ情報（OCG）。Acrobat がレイヤ構造も解析する | PC3 の「レイヤ情報を含める」をオフ | PC3 の設定（INSTALL.md） |

コード内では `[Acrobat軽量化 #n]` のコメントで各箇所を示しています。

## 設計判断

- **「画層の非表示」は Plottable（印刷可否）で実装しました。** フリーズや表示オフにすると作業中の画面まで変わります。現在画層はフリーズできないという制約もあります。印刷可否なら画面はそのままで、PDF にだけ出ません。
- **TrueType 化は文字スタイルのフォントを一時的に差し替えて実現しました。** -PLOT コマンドには「SHX を TTF にする」オプションがありません。そこで、出力の直前だけ STYLE の FontFile を TTF に替え、直後に元へ戻します。
- **「文字を線画にしない」には PC3 の「すべての文字をジオメトリに変換」をオフにする必要があります。** これは PC3 側の設定で、LISP からは変えられません。INSTALL.md でカスタム PC3 を作る手順を示しています。
- **復元は自前のリストで行います。** レイヤ状態（layerstate）を使うと図面に名前付きの状態が残ります。そのため、元の値は LISP 内のリストに保持します。
- **BACKGROUNDPLOT=0（前景印刷）にしています。** バックグラウンド印刷だと、印刷が終わる前に復元処理が走ってしまいます。
- **既存ファイルは変更しません。** PDF は連番を付けて新しく作り、dwg は保存しません。ページ設定の変更を保存するかという質問には N で答えます。
- **エラー時も復元します。** `*error*` から `LP:restore-all` を1回だけ呼びます。

## 既知の制約

- SHX と TTF では字幅が違うため、PDF 上で文字の長さが少し変わることがあります（図面データは変わりません）。
- MTEXT の書式コードで直接指定したフォント（`\Fromans.shx;` など）は差し替えの対象外です。
- 対象画層以外に置かれたハッチングは残ります。必要なら `*LP:HeavyLayers*` に画層名を追加してください。
- 外部参照（XREF）のスタイルや画層も一時変更の対象です。メモリ上での変更なので、外部参照ファイル自体は変わりません。
